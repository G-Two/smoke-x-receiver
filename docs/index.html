ESP32 Receiver for ThermoWorks Smoke X2/X4

Open-source ESP32 + LoRa firmware for the ThermoWorks Smoke X2 and Smoke X4 wireless thermometers.

What it does

The ThermoWorks Smoke X2 and Smoke X4 are excellent BBQ / smoker thermometers — accurate, long RF range, long battery life, no app required. But the included receiver only shows the current probe readings. There's no way to record history, set alerts beyond the built-in alarm, or integrate with home automation.

This project turns a low-cost Heltec WiFi LoRa 32 board (~$15) into an additional, network-connected receiver that runs alongside the original Smoke X2/X4 receiver without interfering with it. All paired receivers continue to function normally.

Compatibility note: this firmware works with the ThermoWorks Smoke X2 and Smoke X4 only. It is not compatible with the original ThermoWorks Smoke or ThermoWorks Signals products — different RF protocols.
  • Built-in web UI — connect to the device and see current temperatures plus a live history graph in any browser.
  • MQTT publishing — publishes JSON status messages on every base-station transmission (every 30 seconds) for use with Home Assistant or any other MQTT consumer.
  • Home Assistant integration — auto-discovery via MQTT. Probe temperatures, attached/detached state, alarms, and Billows target temperature all show up as Home Assistant entities automatically.
  • Standalone mode — for field use without home Wi-Fi, runs as its own access point.
  • HTTP API — JSON endpoint for current state and probe history; consumable by any HTTP client.

How it works

Temperature readings flow via the LoRa RF signal from the Smoke X2/X4 base station to both the included receiver and to an ESP32+LoRa device. The latter publishes the data over MQTT (for Home Assistant or any other consumer) and serves it from a built-in web UI. All data is acquired, processed, and stored locally — no cloud dependency unless you choose (e.g., AWS IoT MQTT)

Compatible hardware

Any ESP32 board with a SPI-connected Semtech SX1276 or SX1262 LoRa transceiver operating in the 915 MHz ISM band will work. The supported and tested boards are:

  • Heltec WiFi LoRa 32 V2 (ESP32 + SX1276)
  • Heltec WiFi LoRa 32 V3 (ESP32-S3 + SX1262)

After flashing

The receiver boots into Wi-Fi access-point mode the first time. From your phone or laptop, join the network Smoke X Receiver (default password The extra B is for BYOBB), then open http://192.168.4.1/wlan to point the receiver at your home Wi-Fi.

Once on Wi-Fi, the device:

  1. Acquires a DHCP address and requests hostname smoke_x.
  2. Waits for a sync transmission from a Smoke X2 / X4 base station — put the base into pairing mode and the receiver will pair on the first burst.
  3. Begins receiving temperature transmissions (every ~30 s) and publishes them over MQTT (if enabled) and the web UI.

Full setup details — Smoke X pairing flow, MQTT URI / TLS configuration, Home Assistant auto-discovery setup — are in the project setup guide.
